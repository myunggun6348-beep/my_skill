# 학생별 기록 일괄 작성·검수

입력 사실에 근거한 학생별 `검토용 초안`과 기계적 검수 보고서를 함께 만든다. 문장 생성과 규정·분량·중복 검수를 분리하고, 수정 후 검수를 반복한다.

## 참고자료 선택하기

- 입력 파일을 처리하기 전에 [입출력 데이터 계약](references/data-contract.md)을 읽는다.
- 학교생활기록부 문장을 작성하거나 검토하기 전에 [공식·교내 기준 연결 방법](references/official-guidance.md)을 읽고, `references/official/`에 사용자가 넣은 최신 공식 기재요령과 교내 기준을 우선 확인한다.
- 초안 작성과 검수 기준이 필요하면 [작성·검수 규칙](references/review-rules.md)을 읽는다.
- 공식 기재요령, 교육부 훈령, 교내 지침이 서로 다르면 최신 공식 자료를 우선하고, 교내 지침은 공식 범위 안에서 적용한다. 확정할 수 없는 사항은 `확인 필요`로 분리한다.

## 작업 흐름

### 1. 작업 기준 확정하기

다음을 입력에서 확인한다.

- 대상 학년도, 학년, 기록 영역, 과목 또는 활동
- 목표 글자 수와 최대 글자·바이트 수
- 학교 내부 금지 표현 또는 별도 문체 기준
- 신규 초안 작성인지 기존 문장 검수인지

자료가 없으면 `assets/audit-config.json`의 기본값을 사용하되, 적용 학년도와 공식 기재요령이 일치하는지 먼저 확인한다. 최대치를 채우기 위해 내용을 늘리지 않는다.

### 2. 입력 정규화하기

학생이 10명 이상이거나 파일 입력이면 다음을 실행하여 열 이름과 누락 항목을 먼저 점검한다.

```text
python scripts/normalize_input.py <입력파일> --output normalized-input.json
```

- XLSX는 기본적으로 첫 번째 표시 시트를 읽는다. 다른 시트는 `--sheet`로 지정한다.
- CSV, TSV, XLSX, JSON, Markdown 표, `항목: 값` 텍스트 블록을 지원한다.
- 표에 없는 사실을 추론하여 빈칸을 채우지 않는다.
- 동일 학번, 식별 정보 없음, 활동·관찰 근거 없음 경고를 먼저 해소하거나 `확인 필요`로 유지한다.
- 학생 식별자는 출력 행의 연결에만 사용하고 기록 문장 안에는 불필요하게 넣지 않는다.

### 3. 학생별 근거 카드 만들기

학생마다 다음 항목을 정리한다.

- 맥락: 영역, 과목·활동, 시기, 주제
- 역할: 실제 맡은 일
- 행동: 발언, 질문, 선택, 조사, 제작, 설명, 조율, 수정
- 과정: 사용한 방법, 문제 대응, 피드백 반영
- 결과: 확인 가능한 산출물, 변화, 기여
- 교사 관찰: 반복된 태도나 성장

각 핵심 서술을 입력 근거에 연결한다. 근거가 부족하면 문장을 꾸며 완성하지 말고 별도 `확인 필요` 열에 적는다. 학생 자기진술을 교사 관찰 사실로 바꾸지 않는다.

### 4. 학생별 검토용 초안 작성하기

- 실제 활동과 관찰된 행동만 사용한다.
- `맥락 → 구체적 행동·역할 → 과정·문제 해결 → 확인 가능한 결과·성장` 순서를 기본으로 자연스럽게 쓴다.
- 역량·태도·성장은 같은 문맥의 행동 근거와 함께 서술한다.
- 진로 연결, 내면 변화, 성취, 인과관계를 입력에 없으면 만들지 않는다.
- 입력 순서를 유지하고 학생마다 한 행을 만든다.
- 사실을 바꾸지 않은 채 문장 구조와 강조점을 달리한다. 단순 동의어 치환만으로 중복을 숨기지 않는다.
- 결과 제목이나 파일 열은 `검토용 초안` 또는 `draft_text`로 표시한다. `완성본`, `최종본`으로 부르지 않는다.

초안 표는 `assets/draft-output-template.csv`의 열 순서를 사용한다. 최소한 `student_id`, `name`, `area`, `draft_text`, `evidence_summary`, `check_needed`, `excluded_items`를 포함한다.

### 5. 분량·금지 표현·중복 검수하기

초안을 CSV, TSV, XLSX 또는 JSON으로 저장한 뒤 다음을 실행한다.

```text
python scripts/audit_records.py <초안파일> --config assets/audit-config.json --phrases assets/prohibited-expressions.tsv --output-dir audit-output
```

다음 파일을 확인한다.

- `student-audit.csv`: 학생별 글자·바이트·표현·근거·중복 문제
- `duplicate-pairs.csv`: 유사도가 높은 학생 쌍과 공통 구간
- `priority-report.md`: P1, P2, 통과 순서의 수정 보고서

P1부터 수정한다.

1. 빈 초안, 근거 요약 누락, 최대 분량 초과, 고위험 금지 표현, 동일·고유사 문장
2. 확인 필요, 주의 표현, 최대치 임박, 중간 수준 유사 문장
3. 검수 통과 문장에 대한 교사 최종 확인

유사 문장을 수정할 때 학생별 고유 행동·과정·결과를 중심으로 재구성한다. 새로운 사실을 추가하지 않는다. 수정 후 같은 명령으로 다시 검수하여 P1이 남지 않았는지 확인한다.

### 6. 결과 묶음 만들기

다음 순서로 제공한다.

1. `학생별 검토용 초안`: 원래 학생 순서 유지
2. `수정 우선순위 보고서`: P1 → P2 → 통과
3. `중복 검수 결과`: 학생 쌍, 유사도, 공통 구간, 수정 방향
4. `분량 점검`: 글자 수, UTF-8 바이트, 적용 상한
5. `제외·확인 사항`: 근거 부족, 기재 가능성 미확정, 제외한 표현

마지막에 다음 확인 문구를 붙인다.

`교사 확인: 실제 수행, 허위·과장, 기재금지사항, 최신 공식 기재요령과 학교 내부 기준을 대조한 뒤 최종 입력`

## 검수 원칙

- 낮은 중복 점수를 품질 보증으로 간주하지 않는다. 사실 근거와 영역 적합성을 별도로 확인한다.
- `assets/prohibited-expressions.tsv`는 시작 목록이다. 최신 공식 기재요령과 교내 기준을 반영해 추가·수정한다.
- 규정상 기재 불가한 사실을 우회 표현으로 바꾸지 않는다.
- 개인정보가 포함된 원본과 결과물은 사용자가 지정한 작업 범위 안에서만 다룬다.
- 자동 검수 결과보다 공식 기재요령과 교사의 실제 관찰 기록을 우선한다.
