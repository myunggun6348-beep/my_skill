# 입출력 데이터 계약

## 1. 허용 입력

| 형식 | 처리 방식 |
|---|---|
| XLSX | 첫 번째 표시 시트 또는 `--sheet`로 지정한 시트의 첫 행을 열 이름으로 사용 |
| CSV·TSV | UTF-8 또는 UTF-8 BOM을 권장하며 구분자를 자동 판별 |
| JSON | 객체 배열 또는 `records` 배열 사용 |
| Markdown 표 | 첫 행을 열 이름, 둘째 행을 구분선으로 사용 |
| 일반 텍스트 | 빈 줄 또는 `---`로 학생을 나누고 `항목: 값` 형식 사용 |

구조화되지 않은 짧은 텍스트는 에이전트가 직접 읽을 수 있다. 학생 수가 많으면 먼저 `scripts/normalize_input.py`로 정규화한다.

## 2. 권장 입력 열

| 표준 열 | 필수성 | 내용 | 허용 별칭 예 |
|---|---|---|---|
| `student_id` | 권장 | 학번 또는 내부 식별자 | 학번, 번호, 학생ID |
| `name` | 권장 | 학생 이름 | 이름, 성명 |
| `grade` | 조건부 | 학년 | 학년 |
| `area` | 필수 | 기록 영역 | 영역, 기록영역 |
| `subject` | 조건부 | 교과명 | 과목, 교과 |
| `activity` | 필수 | 실제 활동 | 활동, 활동내용, 주제 |
| `role` | 권장 | 실제 역할 | 역할, 담당 |
| `process` | 권장 | 수행 과정과 방법 | 과정, 수행과정 |
| `outcome` | 권장 | 확인 가능한 결과물·변화 | 결과, 결과물, 산출물 |
| `teacher_observation` | 권장 | 교사가 관찰한 행동 | 관찰, 교사관찰, 관찰내용 |
| `student_statement` | 선택 | 학생 자기진술 | 학생소감, 자기평가 |
| `target_characters` | 선택 | 학생별 목표 글자 수 | 목표글자수, 목표분량 |
| `existing_text` | 선택 | 검토할 기존 문장 | 기존문장, 원문 |

`student_statement`는 학생 자기진술로 유지하며 교사 관찰로 단정하지 않는다. 임의의 추가 열은 `source_fields`에 보존한다.

## 3. 텍스트 입력 예

```text
학번: 30101
이름: 김가온
영역: 교과 세부능력 및 특기사항
과목: 확률과 통계
활동: 물가지수 자료를 이용한 산점도 분석
역할: 자료 정제와 그래프 작성
과정: 이상치를 확인하고 기준을 바꾸어 재계산함
결과: 분석표와 해석문을 제출함
교사관찰: 기준 변경 이유를 질문에 답하며 설명함

---

학번: 30102
이름: 이나래
영역: 교과 세부능력 및 특기사항
...
```

## 4. 정규화 결과

`normalize_input.py`는 다음 구조의 JSON을 만든다.

```json
{
  "source": "student-input.xlsx",
  "count": 2,
  "warnings": [],
  "records": [
    {
      "record_key": "30101",
      "student_id": "30101",
      "name": "김가온",
      "area": "교과 세부능력 및 특기사항",
      "evidence_text": "...",
      "source_fields": {}
    }
  ]
}
```

`warnings`에 동일 식별자, 학생 식별 정보 없음, 활동·관찰 근거 없음이 있으면 초안 작성 전에 확인한다.

## 5. 초안 출력 열

| 열 | 내용 |
|---|---|
| `student_id` | 입력과 연결할 식별자 |
| `name` | 학생 이름 |
| `area` | 적용 영역 |
| `draft_text` | 검토용 초안 |
| `evidence_summary` | 초안의 핵심 사실과 연결되는 입력 근거 |
| `check_needed` | 교사가 확인할 조건·누락 정보 |
| `excluded_items` | 금지·근거 부족으로 제외한 입력 |

열 이름은 유지한다. `audit_records.py`가 이 이름과 대표적인 한국어 별칭을 인식한다.
