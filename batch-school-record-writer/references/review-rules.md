# 작성·검수 규칙

## 근거성

- 활동, 역할, 발언, 수행 과정, 산출물, 변화, 교사 관찰 중 입력에 명시된 사실만 사용한다.
- 학생 자기평가와 소감은 학생의 진술로 다루며 교사가 관찰한 내면 변화로 바꾸지 않는다.
- `열심히`, `우수함`, `탁월함`, `역량이 뛰어남`처럼 평가적인 표현은 이를 뒷받침하는 구체적 행동이 같은 문맥에 있을 때만 사용한다.
- 근거가 없으면 삭제하거나 `check_needed`에 옮긴다.

## 개별성

- 같은 활동을 한 학생도 역할, 선택, 질문, 방법, 수정 과정, 산출물의 차이를 중심으로 쓴다.
- 공통 활동 설명은 짧게 유지하고 학생 고유 행동에 문장 비중을 둔다.
- 문장 시작과 종결 표현만 바꾸는 방식으로 중복을 낮추지 않는다.
- 서로 다른 학생에게 같은 성장·역량 판단을 반복하려면 각 학생의 별도 근거가 있어야 한다.

## 분량

- 설정 파일의 `target_characters`는 목표값이고 `max_characters`, `max_bytes_utf8`은 상한이다.
- 핵심 근거를 먼저 남기고 공통 활동 설명, 수식어, 반복된 평가어 순으로 줄인다.
- 분량을 늘릴 때 새 사실을 만들지 않는다. 추가 근거가 없으면 짧은 문장을 유지한다.
- 줄바꿈은 `\n`으로 정규화하고 UTF-8 인코딩 바이트를 계산한다.

## 표현 검사

`assets/prohibited-expressions.tsv`의 등급을 다음처럼 해석한다.

- `high`: 공식 기재 가능성이나 사실성에 중대한 위험이 있어 P1로 검토
- `medium`: 문맥과 근거를 확인해야 하므로 P2로 검토
- `low`: 문체 개선 후보

표현 목록은 완전한 규정집이 아니다. 공식 기재요령 원문과 교내 기준으로 추가한다. 단순 문자열 탐지는 문맥을 판단하지 못하므로 탐지 사실만으로 최종 삭제를 결정하지 않는다.

## 중복 검사

자동 중복도는 문장 순서 유사도, 낱말 집합, 글자 3-그램을 함께 계산한다.

- `exact`: 정규화 후 동일한 문장
- `high`: 설정값 이상의 고유사 문장으로 P1
- `medium`: 공통 구조가 많은 문장으로 P2

공통 활동명 때문에 점수가 높아질 수 있다. `common_excerpt`와 실제 근거 카드를 함께 보고 판단한다. 점수가 낮아도 사실이 비슷하거나 표현만 기계적으로 바뀌었다면 다시 쓴다.

## 수정 우선순위

| 우선순위 | 대표 사유 | 조치 |
|---|---|---|
| P1 | 빈 초안, 근거 없음, 상한 초과, 고위험 표현, exact/high 중복 | 배포 전 반드시 수정 |
| P2 | 확인 필요, 주의 표현, 상한 임박, medium 중복 | 교사 근거와 문맥 확인 후 수정 |
| 통과 | 자동 검수상 중대한 문제 없음 | 실제 수행과 공식·교내 기준 최종 대조 |

자동 검수 통과는 기재 가능성의 최종 판정이 아니다.
